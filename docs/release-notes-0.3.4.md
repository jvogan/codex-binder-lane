# Codex Binder Lane 0.3.4

Codex Binder Lane 0.3.4 describes the complete campaign workflow in plain English.

## Changes

- Let the user choose the structure, site, tools, scale, metrics, and stop rules, or ask Codex to propose them.
- Run plugins, APIs, cloud compute, local tools, or a mix.
- Compare matched workflows with the same metrics.
- Filter candidates and run a fixed number of design rounds.
- Deliver sequences, structures, metrics, rankings, snapshots, interactive views, images, optional animation or video, costs, and raw files.
- Keep the public repository reproducible from the private source exporter.

## Validation

The release checks the exact public file set, plugin ZIP layout, assets, metadata limits, activation tests, Python 3.10 through 3.14 support, and an isolated install.

The source tag is `v0.3.4`.
