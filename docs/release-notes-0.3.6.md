# Codex Binder Lane 0.3.6

Codex Binder Lane 0.3.6 keeps the full computational binder-design workflow available through GitHub.

## Changes

- Lead with the real product model: give Codex a target and constraints, then let Codex choose, run, compare, iterate, and deliver.
- Recommend a focused set of computational companions for design, prediction, target data, structure review, and sequence review.
- Keep parallel lanes, metric-based iterations, mixed routes, complete sequences, target–binder structures, visuals, video, and reports first-class.

The release checks the exact public file set, plugin metadata, companion guidance, package language, Python 3.10 through 3.14 support, and an isolated installation.
