# Codex Binder Lane 0.3.5

Codex Binder Lane 0.3.5 keeps the complete workflow computational.

## Changes

- Keep the user-facing product model unchanged: give Codex a target and constraints, then let Codex plan, run, compare, refine, and deliver.
- Use target-site language consistently across the skill, contracts, fixtures, and tests.
- Limit the shipped plugin to computational protein design and evaluation.
- Add a package-wide regression test for the removed terminology.

## Validation

The release checks the exact public file set, plugin ZIP layout, assets, metadata limits, activation tests, package language, Python 3.10 through 3.14 support, and an isolated install.

The source tag is `v0.3.5`.
